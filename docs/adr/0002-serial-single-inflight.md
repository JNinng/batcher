# 串行单在途批次，计时器自组批起算

同一时刻至多一个 In-flight Batch：批次函数执行期间新 Item 只排队等待，下一个批的计时器从 Formation 起点（第一条 Item 进入空批）起算，而非从 Item 到达时刻。下游并发因此恒为 1、行为可预测；代价是 interval 为尽力而为的软上限——下游执行慢时 Item 端到端等待可超过 interval，且慢执行后不会用到达时刻补偿触发碎片小批。备选方案各有硬伤：流水线（多在途）使下游并发不可控；到达时刻计时会在慢下游之后产生大量 1~2 条的碎片批，放大下游压力。真有吞吐瓶颈时再加 MaxConcurrency 选项，不推翻本决定。
